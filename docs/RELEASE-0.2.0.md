# 邻间 0.2.0

- 合并原频道 / 共享空间到群聊，移除独立入口，统一使用“聊天 / 文件 / 成员”标签，默认进入聊天。
- 私聊增加“聊天 / 文件”标签，默认聊天，文件页集中查看附件；普通私聊支持搜索、分类、排序、选中下载和下载记录，可信节点私聊也可从文件标签查看往来附件。
- 群管理增加发布权限：默认全员可发言上传，也可仅允许群主与指定成员发布；其他成员只读下载。支持群简介、成员管理、归档与解散。
- 群文件支持直接上传文件和文件夹、名称搜索、文档/图片分类、排序、分页、选中下载、共享者和时间、类型图标及真实下载记录。
- 群邀请支持有效期、人数额度、撤销，以及每个地址独立复制和二维码。新成员权限遵循群设置，可查看全部历史。
- 自动迁移已有共享空间为群聊，保留 ID、消息、文件、成员、贡献者、邀请与归档状态，并保留原只读发布限制。普通旧群聊继续全员发布。
- 成员撤权后拒绝消息、附件、分块、原文件及既有下载 ticket 的新访问，轮询清理对应内容和传输任务，保留其他群的暂停任务。
- 修复上传文件夹时正常轮询误报“会话已切换”：插件和网页按会话 ID、连接类型及会话身份检查，实际切换时仍取消上传。
- 修复较早轮询响应误把新建/刚加入群聊判为撤权的问题；修复网页服务未提供文件夹打包脚本的问题。
- 提供 Windows、macOS、Linux 的 x64 / ARM64 六个平台包。

## 边界与验证

无需密码账号，昵称不证明真实身份。已有下载、截图、收藏副本不能远程收回。归档保留阅读，解散保留服务器磁盘数据；个人移除会话仅隐藏自己的列表项。当前为 JSON 存储，跨重启续传、SQLite 与磁盘生命周期清理尚未包含。

验证包含后端测试与静态检查、五组前端测试、迁移权限回归，以及网页端旧空间转群、默认聊天、权限保存、群文件历史保留的实际操作。六个平台包交叉构建并校验；macOS / Linux / ARM64 的 DBX 真机安装仍需对应设备验证。
