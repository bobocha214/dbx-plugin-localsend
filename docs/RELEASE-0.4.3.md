# 邻间 0.4.3

- 插件主题改用独立的 data-im-theme 状态及配色，不再读取 DBX 注入的颜色变量，避免深色界面残留白色面板。
- 浅色、深色为插件内显式选择；跟随系统依据操作系统配色，并响应系统主题变化。
- 统一侧栏、通讯录、设置、分享、输入框及辅助提示的深色配色；主要操作按钮使用独立的背景与文字颜色。
- 复制等提示使用浏览器顶层 popover，在弹窗打开时归属当前弹窗，避免被原生 dialog 或遮罩覆盖。旧内核回退为弹窗内提示。

验证：主题与提示专项测试、设置分享测试、前端回归测试。在不含 allow-same-origin 的沙箱中注入宿主白色配色变量，验证深色连接面板与分享面板，实测复制提示位于弹窗前层。
