# 邻间 0.1.0

将本轮局域网 IM 开发成果整合到本地 main，并将发布版本重新定为 0.1.0。0.4.x 文档保留为开发迭代记录。

- 免登录游客模式、固定局域网大厅、私聊和群聊，支持可选中心服务及可信节点通信。
- 文字、图片、文件和文件夹 ZIP 传输；上传和下载支持当前窗口内的断点续传。
- 图片表情收藏、会话文件列表、真实下载状态记录，以及 Office 等文件类型图标。
- 设置标签页、独立浅色与深色主题、存储路径选择和多网卡地址展示。
- 每个分享地址提供复制和二维码；提示显示在弹窗前层。

安装包：`dist/io.github.yuzhi.localsend-0.1.0-windows-x64.dbxp`。

版本号调整不改变插件 ID 和数据目录约定。如果 DBX 对已安装的 0.4.x 执行版本降级限制，需要按宿主支持的本地安装方式处理。
