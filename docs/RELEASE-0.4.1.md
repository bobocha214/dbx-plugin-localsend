# 邻间 0.4.1

修复下载记录页面只读取本地列表、实际下载没有写入记录的问题。

- 完成校验并在宿主 finish 或浏览器 writer.close 成功之后，才记录“已保存”。保存失败不显示成功。
- 网络中断/暂停记录已确认接收字节数。继续下载后更新同一条任务记录。
- 普通浏览器下载链接记录“已交给浏览器 · 完成状态未知”，不猜测浏览器最终是否保存成功。
- 记录由当前服务按访客保存，重启服务后仍保留；界面按当前会话筛选。
- 未同步的记录在当前窗口暂存，再打开下载记录时重试同步。断网且关闭窗口前未能同步的记录无法恢复。
- 会话文件列表遍历完整消息历史，并读取附件实际名称和大小。
- 不导入旧的 localStorage 列表，旧版本未记录过的下载无法追溯补录。

验证覆盖：下载暂停/恢复、保存完成顺序、原生保存失败、浏览器移交、服务重启持久化及访客隔离。
