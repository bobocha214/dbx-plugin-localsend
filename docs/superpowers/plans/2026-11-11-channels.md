# 频道管理实现计划

目标：免登录模式下按频道共享不同文件，默认仅指定成员可访问，管理员可开启限时邀请。

架构：频道作为新的 conversation kind 复用消息、附件成员校验；独立 channels.go 实现管理、邀请和文件索引。归档允许阅读、禁止新增，解散撤销所有服务端访问。成员为只读或可贡献；频道拥有者与本机管理员可管理。新增成员可访问频道全部历史，邀请持有者在有效期及次数内可加入。

- [x] 后端：持久化频道简介、归档状态、贡献者名单、邀请；创建、更新、解散、加入和撤销邀请接口。
- [x] 权限：非成员拒绝消息、元数据、分块、content 和下载 ticket；只读/归档禁止消息和文件上传；管理员管理成员。
- [x] 文件：按会话分页列表，搜索、分类、排序，批量下载由客户端逐文件执行。
- [x] Web：频道/私聊分组，创建/管理/邀请页面，频道聊天/文件/成员标签，移动端与深色样式。
- [x] 撤权：刷新后清理已失去访问权的当前会话、图片缓存、草稿及待传输任务，防止旧异步结果恢复内容。
- [x] 验证：频道权限、邀请过期/撤销/用尽、归档解散、跨重启、分页、现有回归；版本 0.2.0，生成六平台包。

SQLite、跨重启续传和存储迁移重构作为后续独立改进，不与本次频道版本混合。

验证记录：后端 go test ./... -count=1、go vet ./...；五组 Node 前端测试与语法检查；隔离沙箱和普通网页实测频道创建、只读邀请加入、贡献授权、搜索、二维码、深色/390px 窄屏和撤权清理。六个平台包已交叉构建并通过 verify-package.py。macOS/Linux/ARM64 真机 DBX 安装未验证。

## 后续统一为群聊

用户确认合并独立共享空间到群聊。已实现：保留原 ID 和历史的权限安全迁移；普通群聊默认全员发布；统一聊天/文件/成员、发布限制与指定贡献者、邀请、归档和解散。新增迁移与统一权限测试，以及旧轮询误撤权的回归测试。
