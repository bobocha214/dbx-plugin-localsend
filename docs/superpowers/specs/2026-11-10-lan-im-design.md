# 局域网 IM 设计（已批准）

混合组网：DBX 启动本地节点，自动发现并可信直连；可开启中心服务，提供邀请注册、稳定账户、离线消息和历史。完整网页客户端与 DBX 共用 UI。中心群聊不做分布式成员管理。

账户：首位管理员仅在宿主本地初始化；有期限、使用次数受限的邀请；密码安全哈希；昵称、头像、简介；改密撤销旧会话；停用立即拒绝访问。账户与节点密钥独立，IP 和昵称不是身份。会话令牌不得暴露到网页 URL 或日志。

消息：单聊、中心群聊、消息 ID 去重、发送中/服务接收/失败重试、未读、历史搜索。草稿与阅读位置不因轮询重建丢失。图片预览和文件按会话授权，分块传输、取消、校验，不整体载入内存。

直连：持久 Ed25519 节点身份、UDP 自动发现、首次互信确认、签名验证、防重放；中心身份与直连权限独立。网页依赖其节点在线。

界面：导航、会话、聊天主区，资料按需展开；DBX token、移动端、键盘和输入法适配；应用内弹窗，不依赖 alert/confirm/prompt。旧数据不自动归属新账户。

运行：保留插件 ID；新版本 0.2.0；Go 后端，不引入外部服务依赖；新 IM 数据使用插件数据目录下 im/，不迁移或覆盖旧频道。浏览器登录若使用明文 HTTP，UI 明示传输未加密并建议仅可信局域网；不声称端到端加密。
