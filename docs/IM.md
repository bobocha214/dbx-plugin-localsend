# 邻间 · 局域网 IM 0.1.4

这是插件的新默认工作台。旧版频道文件与历史不被迁移或覆盖，`ui/legacy.html` 仅作为源代码参考保留，不通过新网页服务公开。旧服务的自动启动已关闭。

## 首次使用

1. 在 DBX 打开插件工作台即可进入聊天，无需注册、登录或邀请码。插件为本机自动保存身份；浏览器首次访问时填写昵称即可加入。
2. 插件自动启动本地节点；也可在连接设置重试启动，默认 TCP 53318。该节点同时提供网页入口，关闭 DBX 后服务停止。
3. 同事在同一局域网打开界面显示的地址，以昵称加入公共大厅。大厅内容及其附件向该节点的所有访客开放，请勿在大厅发送私密内容。昵称只是显示名称，不能作为真实身份的证明。
4. 通过通讯录开始单聊或创建群聊。图片支持拖放、粘贴与预览；文件分块上传，传输失败可重试。单聊与群聊按各自成员授权，不会自动成为公共大厅内容。
5. 其他 DBX 用户可以在连接设置输入中心地址。地址必须是本机或私有网段的 IP，例如 `http://192.168.1.10:53318`；不接受域名、跳转或公网地址。

## 两种连接

中心聊天的用户身份属于该中心，中心在线时才能发送；消息持久保存在服务节点，收件人再次访问后拉取历史。切换中心会建立该中心的访客身份，不会按照同名用户合并身份或聊天记录。

可信直连属于电脑节点身份，保存在本机长期 Ed25519 密钥中，与 IP 和网卡无关。双方在本机开启节点后，经 UDP 239.255.53.19:53319 发现对方，在其他可信渠道核对完整节点 ID 并分别确认信任，之后可以直接收发。无需连接外部中心，但本机自动身份即可使用，无需登录。普通网页用户不能读取或控制节点直连记录。节点签名验证身份和完整性，不提供消息内容加密。

Windows 防火墙需允许所选 TCP 端口及 UDP 53319；禁止多播的企业网络可能无法自动发现。界面显示服务地址与发现错误。第一版不会自动为机器修改防火墙规则。

## 账户与数据

头像接受 PNG、JPEG、WebP。默认采用免登录访客身份，浏览器昵称不会赋予读取他人私聊或控制节点直连的权限。旧账户与邀请注册数据归档保留，不删除，也不自动公开为大厅内容。

新数据位于 `$DBX_PLUGIN_DATA_DIR/im/`：`state.json` 保存身份、消息、会话和附件元数据，`files/` 保存附件，`node/` 保存节点密钥、信任与直连记录。应在停止服务后整体备份此目录；只复制头像或文件不会恢复完整聊天。节点私钥和登录会话也属于备份的敏感数据。

当前存储是原子替换的本地 JSON，适合小型局域网团队；不是多进程共用或大规模部署数据库。不要同时以多个进程打开相同数据目录。文件不自动清理，管理员需管理磁盘空间。

HTTP 传输为明文，仅应在可信局域网使用，不是端到端加密产品。部署 TLS 反向代理时浏览器可使用 HTTPS，但代理需要保持真实 Host，插件连接中心不接受重定向。文件传输不设产品层面的文件大小上限，逐块处理，实际可传大小取决于磁盘空间、文件系统、浏览器及宿主环境。网页下载在支持原生保存 API 时流式保存；DBX 优先使用宿主文件传输 API。不支持原生流式保存的浏览器通过短期、一次性下载地址交由浏览器直接保存，不将整个文件缓存在页面内存。图片预览仍有独立内存保护限制，不影响原文件下载。

## 开发验证

在 `backend/` 执行：

```powershell
go test ./...
go vet ./...
go build -o ../dist/dbx-plugin-localsend.exe .
```

在仓库根目录执行：

```powershell
node --check ui/im.js
node ui/im.test.js
```

当前版本为 0.1.2。运行 `./scripts/package-im.ps1 -Target windows-x64` 生成指定平台包；支持 Windows、macOS、Linux 的 x64 / ARM64 六个 target。脚本需要 Go、PowerShell 7 和 Python 3.8+。发布步骤见 [RELEASING.md](RELEASING.md)。本机构建和静态校验不能替代对应系统、架构上的 DBX 安装及两台物理设备联调。
