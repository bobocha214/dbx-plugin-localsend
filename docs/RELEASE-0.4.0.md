# 邻间 0.4.0

- 聊天工具栏的文件、表情、文件夹和传输任务按钮统一边框、间距；文件与表情紧邻。
- 设置中心采用卡片布局，统一下拉框、路径输入、操作按钮和窄窗口布局。
- Windows 插件的存储目录按钮通过本机文件夹对话框取得完整路径，不使用浏览器目录名冒充路径。浏览器无法配置服务器本机路径。
- 图片预览可“收藏为表情”。收藏保存独立图片副本，按当前访客隔离，重启服务后仍保留。表情面板支持发送和移除图片收藏。GIF、PNG、JPEG、WebP 可收藏，单张沿用图片预览的 16 MB 上限。
- Windows 插件支持原生文件夹选择和后台 ZIP 打包，包含空目录。浏览器端文件夹以不压缩的 ZIP64 附件传输，保留中文名称和非空子目录；浏览器选择器不提供空目录。通过 Blob 组合文件引用，按分块读取，不将整个文件夹读进一个数组。
- 上传失败、暂停时保留原任务和附件；继续时重新读取服务器已确认偏移。重建本地文件哈希会读取本地前缀，但不重传已确认的内容。
- 下载在宿主原生保存接口或浏览器 File System Access 保存接口可用时，保留写入句柄、已确认偏移和哈希；暂停或网络失败后可以继续。
- “传输任务”列出当前窗口中未完成的任务，可继续传输。会话身份切换后不能继续原身份的任务。

## 已知范围

断点任务保存在当前窗口中，关闭插件或重启后的任务恢复尚未提供。普通浏览器若只支持下载链接，下载进度由浏览器管理，不提供插件内续传。未实现自动解压，接收者下载 ZIP 后解压。暂停的本机文件夹任务会保留临时 ZIP，成功发送后清理；打包时需要足够的临时磁盘空间。

## 验证

- Go 全量测试与 vet。
- JS helpers、上传/下载中断后恢复测试（包含上传响应丢失）。
- ZIP64 的 CRC、中文和子目录路径，Python zipfile 实际校验和解压。
- 模拟 DBX 的 sandbox iframe（无 allow-same-origin）：设置外观/存储/连接切换、主题、图片收藏和再次发送。与实际 DBX 文件选择/原生保存对接仍需在宿主内确认。
